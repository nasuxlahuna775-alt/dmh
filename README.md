# บอท AI สำหรับ Discord

บอทภาษาไทย ใช้คำสั่ง `/ask` เพื่อส่งคำถามให้ Ollama ที่รันอยู่ในคอม แล้วตอบกลับใน Discord

## สิ่งที่ต้องมี

- Node.js รุ่น 22.12 ขึ้นไป
- บัญชี Discord ที่สร้างแอปและบอทได้
- [Ollama สำหรับ Windows](https://ollama.com/download) และโมเดล AI ที่ดาวน์โหลดไว้ในเครื่อง

## ตั้งค่าบอทใน Discord

1. ไปที่ [Discord Developer Portal](https://discord.com/developers/applications) แล้วสร้าง Application
2. ในหน้า **Bot** สร้างบอทและคัดลอก token เก็บไว้เป็นความลับ
3. ที่ **OAuth2 → URL Generator** เลือก scopes `bot` และ `applications.commands` จากนั้นให้สิทธิ์บอท `Send Messages`, `Use Slash Commands`, `Manage Roles`, `Manage Channels`, `Ban Members`, `Moderate Members`, `View Channels`, `Connect` และ `Speak` แล้วใช้ลิงก์เชิญบอทเข้าเซิร์ฟเวอร์
4. คัดลอก Application ID จาก **General Information**
5. ติดตั้ง Ollama แล้วเปิดแอปทิ้งไว้
6. เปิด PowerShell แล้วดาวน์โหลดโมเดลเริ่มต้นด้วยคำสั่ง:

   ```powershell
   ollama run qwen3:4b
   ```

   รอให้ดาวน์โหลดเสร็จ แล้วพิมพ์ `/bye` เพื่อออกจากหน้าคุย โมเดลนี้มีขนาดดาวน์โหลดประมาณ 2.5 GB

## เริ่มใช้งาน

เปิด terminal ในโฟลเดอร์นี้ แล้วรัน:

```powershell
npm install
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

ถ้ามีไฟล์ `.env` อยู่แล้ว อย่าคัดลอกทับ เพราะจะทำให้ค่า token หายไป เปิดไฟล์ `.env` แล้วใส่ `DISCORD_TOKEN` ของบอท จากนั้นลงทะเบียนคำสั่งและเปิดบอท:

```powershell
npm run register
npm start
```

พิมพ์ `/ask` ในเซิร์ฟเวอร์แล้วใส่คำถาม บอทจะตอบกลับในช่องเดิม

## ปุ่มยืนยันตัวตนเพื่อรับยศ

1. ให้สิทธิ์บอท **Manage Roles** และย้ายยศบอทให้อยู่เหนือยศที่จะมอบ
2. ในห้องที่ต้องการให้มีปุ่ม พิมพ์ `/verify-panel` แล้วเลือกยศในช่อง `ยศ`
3. ตั้งค่า `อายุบัญชี` ได้ตั้งแต่ 0–30 วัน (ค่าเริ่มต้น 7 วัน และ 0 คือปิดการตรวจอายุ)
4. สมาชิกกดปุ่ม **ยืนยันตัวตน** แล้วตอบโจทย์คูณสุ่มภายใน 2 นาที ตอบผิดครบ 3 ครั้งจะพัก 10 นาที

คำสั่งสร้างปุ่มใช้ได้เฉพาะแอดมิน และบอทจะมอบยศหลังผ่านด่านตรวจสอบ

## ต้อนรับสมาชิก กันสแปม และแจ้งปัญหา

- ใน **Developer Portal → Bot → Privileged Gateway Intents** เปิด `Server Members Intent` และ `Message Content Intent`
- ใช้ `/welcome-setup` แล้วเลือกห้องข้อความสำหรับส่งข้อความต้อนรับ
- บอทแบนอัตโนมัติเมื่อสมาชิกส่งอย่างน้อย 7 ข้อความใน 5 วินาที หรือส่งข้อความเดิมซ้ำ 5 ครั้งใน 10 วินาที ลบข้อความย้อนหลัง 10 นาที ยกเว้นแอดมินและผู้มีสิทธิ์ `Manage Messages` หรือ `Ban Members`
- ใช้ `/warn` เพื่อบันทึกคำเตือน และ `/ban` เพื่อแบนด้วยตนเอง ทั้งสองคำสั่งต้องมีสิทธิ์ตามที่ Discord กำหนด
- ใช้ `/ticket-panel` เพื่อวางปุ่มแจ้งปัญหา เลือกยศทีมงานได้ ห้องที่สร้างจะเห็นเฉพาะผู้แจ้ง ทีมงาน และบอท
- บันทึกการตั้งค่าและคำเตือนอยู่ใน `guild-settings.json` ในโฟลเดอร์ข้อมูลของบอท (บน Railway ใช้ Volume ที่ `/data`)

## เพลง YouTube พร้อมแผงควบคุม

- เข้าห้องเสียง แล้วใช้ `/play` วางลิงก์ YouTube
- แผงในห้องข้อความมีปุ่มเล่น/พัก ข้าม หยุด และปรับเสียง ผู้ขอเพลงหรือทีมงานในห้องเสียงควบคุมได้
- บอทต้องมีสิทธิ์ `Connect` และ `Speak`
- การเล่นจาก YouTube ใช้การเชื่อมต่อชุมชนที่ไม่เป็นทางการ จึงอาจหยุดทำงานเมื่อ YouTube เปลี่ยนระบบ และควรเล่นเฉพาะเสียงที่คุณมีสิทธิ์ใช้งาน

## หมายเหตุ

- อย่าแชร์ `.env` หรือ token/API key ให้ผู้อื่น หากเผลอเผยแพร่ให้ยกเลิกและสร้างค่าใหม่ทันที
- ต้องเปิด Ollama และให้โมเดลทำงานบนเครื่องที่บอทเชื่อมถึงได้ก่อนใช้ `/ask`
- ตั้ง `OLLAMA_MODEL` ใน `.env` เพื่อเลือกโมเดลอื่นที่ดาวน์โหลดไว้แล้ว
- บอทจะตอบเร็วขึ้นหลังโมเดลโหลดเข้าหน่วยความจำครั้งแรก แต่ความเร็วขึ้นกับสเปกคอม
- คำสั่ง `/ask` ลงทะเบียนแบบ global จึงไม่ต้องใช้ Server ID; หลังลงทะเบียน Discord อาจใช้เวลาสักครู่ก่อนคำสั่งจะแสดง
- โฮสต์บนคลาวด์ต้องเข้าถึง Ollama ได้ผ่าน `OLLAMA_HOST` ด้วย ค่า `127.0.0.1` หมายถึงเครื่อง/คอนเทนเนอร์ของบอทเอง ไม่ใช่คอมที่บ้าน

## นำบอทขึ้น Railway

โปรเจกต์มี `Dockerfile` สำหรับรันเป็นบริการต่อเนื่องบน Railway

1. อัปโหลดไฟล์โปรเจกต์ขึ้น GitHub โดยไม่อัปโหลด `.env` หรือ `node_modules` (ทั้งสองรายการถูกกันไว้ใน `.gitignore` และ `.dockerignore`)
2. ใน Railway สร้าง Project แล้วเลือก Deploy from GitHub Repo และเลือก repository นี้ Railway จะตรวจพบ `Dockerfile` อัตโนมัติ
3. ในหน้า Variables ของ service เพิ่ม `DISCORD_TOKEN` โดยใส่ token จริงจาก Discord Developer Portal, เพิ่ม `DISCORD_CLIENT_ID` เป็น Application ID, และตั้ง `DATA_DIR=/data`
4. เพิ่ม Volume ให้ service โดยกำหนด Mount Path เป็น `/data` เพื่อเก็บค่าตั้งค่าเซิร์ฟเวอร์และคำเตือนไว้ข้ามการ deploy
5. Deploy แล้วเปิด Logs ตรวจว่ามีข้อความ `บอทออนไลน์แล้ว:`

ก่อน deploy ให้ลงทะเบียนคำสั่ง Discord หนึ่งครั้งจากเครื่องที่มี `.env` ครบ ด้วย `npm run register` (ถ้าแก้คำสั่ง slash ในอนาคต ให้รันซ้ำ)

บอท Discord จะออนไลน์ได้แม้ยังไม่ได้ตั้ง Ollama แต่คำสั่ง `/ask` จะใช้ได้ก็ต่อเมื่อ Railway เข้าถึง Ollama ได้ผ่าน `OLLAMA_HOST` และมีโมเดลตาม `OLLAMA_MODEL` อยู่ในเครื่อง Ollama นั้น
